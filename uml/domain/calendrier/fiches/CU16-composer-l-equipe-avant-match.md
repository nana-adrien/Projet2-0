## CU16 - Composer l'équipe avant-match

| Rubrique | Contenu |
| --- | --- |
| Acteur principal | Capitaine |
| Préconditions | Convocations envoyées, réponses reçues (CU15). |
| Scénario nominal | 1. À partir des joueurs présents, le capitaine compose son équipe : titulaires et remplaçants (F-CAL-07).<br>2. La composition peut être ajustée jusqu'au coup d'envoi.<br>3. Le capitaine désigne le marqueur et un suppléant pour le match (F-LIV-01). |
| Scénarios alternatifs | A1 : ajout d'un joueur occasionnel à la feuille de match en dépannage, sans l'intégrer à l'effectif permanent (F-EFF-06).<br>A2 : la composition est encore ajustée pendant le match par le marqueur (arrivée tardive d'un joueur). |
| Exceptions | - |
| Postconditions | Composition (titulaires/remplaçants) enregistrée ; marqueur et suppléant désignés. |
| Règles | F-CAL-07, F-LIV-01, F-EFF-06 |
