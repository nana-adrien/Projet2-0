## CU26 - Gérer ses préférences de notification

| Rubrique | Contenu |
| --- | --- |
| Acteur principal | Joueur |
| Préconditions | Joueur membre d'au moins un 2-0. |
| Scénario nominal | 1. Le joueur ouvre les préférences de notification d'un 2-0 donné.<br>2. Il choisit un niveau : tout recevoir, seulement buts et score final, seulement infos me concernant, ou aucune (F-NOT-02).<br>3. Il active, s'il le souhaite, un mode « Ne pas déranger » nocturne.<br>4. Il enregistre. |
| Scénarios alternatifs | - |
| Exceptions | - |
| Postconditions | Préférences de notification appliquées pour ce 2-0 (réglages indépendants d'un 2-0 à l'autre). |
| Règles | F-NOT-02 |
