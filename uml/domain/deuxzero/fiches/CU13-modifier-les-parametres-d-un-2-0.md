## CU13 - Modifier les paramètres d'un 2-0

| Rubrique | Contenu |
| --- | --- |
| Acteur principal | Organisateur de 2-0 |
| Préconditions | Le joueur est organisateur du 2-0. |
| Scénario nominal | 1. L'organisateur ouvre les paramètres du 2-0.<br>2. Il modifie la durée de mi-temps, les jours/heure habituels, le délai de validation ou le nombre de transferts autorisés (RG-10 ; F-DZ-08).<br>3. Les changements s'appliquent uniquement aux matchs à venir, jamais aux matchs déjà joués ou en cours.<br>4. L'organisateur peut transférer son rôle à un autre membre (F-DZ-09).<br>5. L'organisateur peut définir la visibilité (public/privé) ou archiver un 2-0 inactif (F-DZ-10, F-DZ-11). |
| Scénarios alternatifs | A1 : modification ponctuelle de la durée de mi-temps pour un seul match, avant son coup d'envoi (RG-10). |
| Exceptions | E1 : tentative de modification d'un match déjà en cours ou terminé -> refusée. |
| Postconditions | Paramètres du 2-0 mis à jour pour les matchs futurs. |
| Règles | RG-10 ; F-DZ-08, F-DZ-09, F-DZ-10, F-DZ-11 |
