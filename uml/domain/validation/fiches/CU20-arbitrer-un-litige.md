## CU20 - Arbitrer un litige

| Rubrique | Contenu |
| --- | --- |
| Acteur principal | Organisateur de 2-0 |
| Préconditions | Match à l'état En litige (contestation refusée, CU19). |
| Scénario nominal | 1. L'organisateur est notifié du litige.<br>2. Il consulte l'écran d'arbitrage : feuille de match, historique des saisies, propositions de correction (F-VAL-05).<br>3. Il tranche : résultat initial, résultat corrigé, ou match annulé.<br>4. Sa décision est définitive et notifiée à tous les membres (RG-13). |
| Scénarios alternatifs | - |
| Exceptions | - |
| Postconditions | Match Officiel ou Annulé ; décision tracée dans le journal d'audit (F-VAL-06). |
| Règles | RG-13 ; F-VAL-05, F-VAL-06 |
